# 連珠名人｜Renju Master

一手の理由まで学べる、連珠・五目並べのAI研究盤です。15路盤を中心に、ヒント、形勢、戦法、棋譜をまとめています。PC・スマートフォンの画面に合わせて配置が変わります。

## GitHub Pages で公開

公開用リポジトリは `uni-tadayasu/renju-master` です。GitHub Pages は `main` の内容を自動公開する構成です。ビルド、npm、APIキー、有料サーバーは不要です。

手動アップロードする場合はフォルダーの**中身**をリポジトリ直下へ置き、`assets` の構造を維持してください。`index.html` をさらに下のフォルダーへ入れないでください。更新は変更したファイルの上書きだけで対応できます。

別のリポジトリで使う場合は、**Settings → Pages → Build and deployment** を開き、**Source = Deploy from a branch / Branch = main / Folder = /(root)** を選んで保存します。空の `.nojekyll` を含めてください。

`.github/workflows/verify.yml` はプルリクエストと `main` 更新時の構文・ルール・戦術解析を検証します。公開処理は GitHub 標準の `pages build and deployment` が担当します。検証だけをローカル実行する場合は `node verify.cjs` を使えます（Node.js が必要）。通常の利用に Node.js は不要です。

## 公開URLとSEO

公開URL `https://uni-tadayasu.github.io/renju-master/` に合わせ、タイトル・説明文・canonical・OGP画像の絶対URL・構造化データ・sitemap.xml・robots.txt を設定済みです。別のURLへ移す場合のみ、同梱の設定スクリプトを実行してください。Python 3 があるPCで、フォルダーを開いて実行します。

```sh
python configure-seo.py https://YOUR-ACCOUNT.github.io/YOUR-REPOSITORY/
```

独自ドメインなら、その正式なHTTPS URLを指定します。スクリプトは `index.html` の正規URL・OGP URL・共有画像の絶対URL・構造化データURLを更新し、`sitemap.xml` を生成、`robots.txt` にサイトマップURLを設定します。この3ファイルをGitHubへ上書きしてください。リポジトリ名まで含む正確なサイトURLを使い、`index.html`・クエリ・`#` は付けません。末尾 `/` の省略時は自動補完します。検索結果への掲載・順位やSNSの画像更新時期は検索サービス側の判断・キャッシュに依存します。

## 使い方

### ヒントを使って対局する

- **先手（黒）・後手（白）**を選びます。黒が先に打ちます。
- **対局研究**では盤面に両者の着手を入力し、AIの候補を見ながら研究できます。外部で打っている対局を再現する使い方もできます。
- **AI対局**では、相手側の着手をAIが担当します。
- ヒントで候補位置・理由・形勢を確認し、必要ならAIの推奨手を盤面に反映します。
- **戻す・進む**で棋譜を一手ずつ移動できます。黒白どちらの着手も、棋譜の先頭まで回数制限なく戻せます。途中から別の手を打つと、その地点から新しい分岐になります。

### 戦法と独自戦法

基本珠型は **26種類すべて（直接13・間接13）** を収録しています。これは最初の三手の形であり、その後のすべての定石・変化を網羅したデータベースではありません。加えて16種類の研究テーマを収録しています。

戦法を選ぶと、その基本配置から研究できます。**戦法工房**で、独自戦法を空の盤面からでも既存の珠型からでも作成できます。AIヒントを見て手を進め、戻して別の候補を試し、名前を付けて保存します。異なる変化は別名で保存すると比較しやすくなります。

棋譜と保存した戦法はブラウザーのローカルストレージを使います。端末間で自動同期されません。**JSON書き出し**でバックアップし、別の端末では読み込んでください。プライベートブラウズの終了、ブラウザーのデータ削除、保存容量の制約などでデータが失われることがあります。

### ルール

- **連珠**：15路盤。黒は五連、白は五連または長連で勝ち。黒の三々・四々・長連は禁手として扱います。
- **自由五目**：黒白とも五つ以上つながれば勝ち。連珠の禁手はありません。
- このサイトは学習用の自由打ち・珠型研究です。スワップや五珠提示などの大会用開局手順、対局時計・大会裁定は実装していません。基本珠型を選ぶ場合は三手が配置された局面から始まります。
- 禁手を自動判定しますが、大会の公式審判を代替するものではありません。

### AI解析と形勢の読み方

AIは端末内のWeb Workerで動きます。反復深化探索、相手の即勝ちへの防御、手の優先順位付けなどを使い、**約1秒の探索予算**で候補を求めます。CPU性能、ブラウザー、局面の複雑さ、バックグラウンド制限によって所要時間・読める深さは変わります。

形勢指数は盤面の脅威や探索結果を数値化した**評価の目安**です。実測された勝率・勝利の保証ではありません。長い強制手順や探索範囲外の手を見落とす可能性があります。世界選手権級エンジンとの対戦検証や棋力認定は行っていません。

### 音声

音声ボタンでナレーションを有効にします。読み上げは端末・ブラウザーの音声合成機能を使用します。日本語音声の種類は端末設定に依存し、初回はボタン操作が必要です。利用できる音声がない環境では、画面のテキスト案内を利用できます。

## ファイルと実行環境

HTML・CSS・JavaScript・画像だけで動く静的サイトです。AI解析にバックエンドは不要です。GitHub PagesなどのHTTPS公開先で利用してください。`index.html` のダブルクリック（`file://`）ではブラウザーの制限でWorkerが起動しないことがあります。

開発中のローカル確認は、Python 3 のあるPCで次のコマンドを実行し、表示されたローカルURLを開きます。

```sh
python -m http.server 8000
```

その場合のURLは `http://localhost:8000/` です。ブラウザーは現在のChrome、Edge、Firefox、Safariを推奨します。小さいウィンドウでは、内容の切り替えやダイアログ内スクロールを使います。スマホはピンチ・ダブルタップ拡大、長押し選択・メニューを抑え、着手前の確認を初期状態で有効にしています。戦法名などの入力欄は文字編集を可能にしています。OS・ブラウザーの強制拡大やアクセシビリティ設定までは変更しません。
